# Primary sources

Reviewed November 16, 2026. These sources establish research alignment, not eligibility, endorsement, or an open submission window.

- [DARPA M-STUDIO program](https://www.darpa.mil/research/programs/m-studio-material-synthesis): atomic-precision synthesis of nanoscale multilayer semiconductor structures and heterogeneous integration. Identifies opportunity HR001124S0019. The live page lists Huanan Zhang as program manager; verify the live contact before outreach.
- [SAM.gov historical M-STUDIO award notice](https://sam.gov/opp/93429a3b60df4bf0b9b3bec04d84381b/view): a September 2024 award notice, not an open solicitation.

No numeric example thresholds in this repository are attributed to DARPA. Consult the applicable official solicitation and amendments for actual requirements. The stack geometry calculation is an explicitly defined arithmetic screen, not a validated physical model taken from these sources.
