# M-STUDIO-aligned research plan

## Scope

The independent ResearchOS TECT HI workspace supports documentation and reproducibility for nanoscale multilayer synthesis and heterogeneous integration. The program's stated direction includes diverse semiconductor materials and sharp multilayer interfaces. See [primary sources](SOURCES.md). The repository makes no claim to implement a universal integration process.

| Stage | Deliverable | Acceptance evidence | State |
| --- | --- | --- | --- |
| Research workflow | Validated records, geometry screening, evidence capture and reports | Automated tests and reproducible synthetic bundle | Implemented |
| Material system selection | Substrate, orientation, material pairs, thicknesses and baseline | Literature-backed rationale and partner capability review | Planned |
| Synthesis protocol | Versioned protocol, equipment, process controls and sample IDs | Reviewed procedure and calibration references | Planned |
| Single-interface study | Structural/compositional and electrical measurements against controls | Raw characterization, uncertainty and independent review | No real data |
| Multilayer study | Repeated-interface uniformity, interface width and defect characterization | Sampling plan, spatially resolved evidence and repeatability | No real data |
| Device integration | Electrical/device behavior and fabrication compatibility | Matched baseline measurements and process-integration review | No real data |

## Laboratory measurements to plan

Track thickness, roughness, interface composition width and defect density with explicit measurement definitions, spatial resolution, sampling and detection limits. Record carrier mobility and device test conditions where relevant. A reported zero count does not establish zero defects; retain the inspected area and detection sensitivity. Compare baseline and candidate under matched conditions with uncertainty.

The workflow records these inputs; a qualified laboratory must select and validate the actual characterization methods. No instruments, growth recipes, physical process solver, or external laboratory integration are configured.

## Next gate

Choose a material system and mechanism, identify experimental partners, establish a versioned protocol and matched control, and define reviewed success criteria. Confirm the current official engagement route before submitting or representing any funding eligibility. No open call is asserted by this repository.
