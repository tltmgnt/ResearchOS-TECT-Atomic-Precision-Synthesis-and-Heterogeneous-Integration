# Contributing

Run `python -m unittest discover -s tests -v` and the README example workflow. Keep synthesis and measurement records explicit about units, method, uncertainty and data kind. Never relabel synthetic values as experimental results. Preserve missing-data semantics and evidence checks.

For new models, document equations, parameter domains, orientation assumptions, reference benchmarks and known limitations. Add tests that check scientific boundaries or failure modes rather than mirroring implementation. Keep credentials and unpublished partner data out of this public repository. Submit a focused pull request explaining behavior and validation.
